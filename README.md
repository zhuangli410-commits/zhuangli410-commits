## 🧠 怎么做事

> **产品判断** → 明确目标用户、核心痛点、最小闭环和边界取舍，不从功能清单开始。
> **直接构建** → 读得懂英文 API 文档，也改得动 Python / JavaScript / TypeScript / Swift。
> **验证交付** → 线上可访问、模拟器跑通、构建产物、真实样本 —— 用可复现的结果说话。
> **复盘迭代** → 每个项目都留了"关键取舍"和"当前边界"，写清楚没做到的，比吹做过的值钱。
